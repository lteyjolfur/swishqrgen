# Swish QR Code Generator

This repository provides two complementary tools for generating and styling Swish QR codes:

- **Node.js script** for fetching QR codes from the Swish API, adding styled backgrounds and text, and saving them as images.
- **Python script** for advanced local image processing, including batch processing, rounded corners, and transparency effects.

## Features

### Node.js (`index.js`)

- Fetches Swish QR codes from the Swish API as PNGs
- Adds a styled colored background and text label to each image
- Saves images to `output_images/`

### Python (`python/main.py`)

- Processes all PNG images in a local folder (`assets/`)
- Adds rounded corners and transparency to images
- Batch processes all images in the folder
- Saves processed images to `assets_processed/`

### Combined Workflow

You can use the Node.js script to fetch and label QR codes, then use the Python script to post-process those images (e.g., add rounded corners or transparency).

## Folder Structure

- `python/` — Python scripts for image processing
  - `main.py` — Main script for processing images and applying styles
  - `assets/` — Source images to be processed
  - `assets_processed/` — Output folder for processed images
- `output_images/` — Output folder for images generated by Node.js (ignored by git)
- `index.js` — Node.js entry point for fetching and styling QR codes

## Usage

### Node.js

1. Install dependencies:

```bash
npm install
```

2. Run the script:

```bash
node index.js
```

3. Images will be saved in `output_images/`.

### Python

1. Place your source images in `python/assets/` (or use images generated by Node.js).
2. Run the main script:

```bash
cd python
python3 main.py
```

3. Processed images will be saved in `python/assets_processed/`.

## Requirements

- Python 3.x
- Pillow (Python Imaging Library)
- Node.js (for fetching and styling QR codes)
